# 考拉旅行搭子，第一版

应用位于 `feature/koala-travel`，基于 upstream 提交
`31759c4d63dd0d0d6580d6f74639ed5315bcd2c3`。基线和其他应用 worktree
独立保留。开机直接显示上海江边、固定考拉、少量问候和观察邀请；没有积分、
限时任务、云账号，也不需要麦克风、自动定位或实时天气。

## 显示与按键

屏幕为 240 × 320；现有硬件规格未注明实际显示区域毫米尺寸。采用半粗字体：
城市标题 36 像素、考拉对话 28 像素、右侧提示和家长设置 24 像素。每条对话
最多两行，每行最多五个 Unicode 字符，文字放在纯色米白底上。长内容拆开，
不缩字号硬塞。三键提示中心为 y=53、160、267，沿整屏高度对应实体上、下、
确定键。电量条使用 BSP 真实读数，读数不可用时为空心条。
软件渲染只能证明布局和字形选择；实物可读性、户外对比度和最终中文显示仍需实机观察。

- 上键：显示并轮换本地问候。
- 下键：显示并轮换一个观察邀请。
- 确定：回应，鼓励三秒后回首页。
- 长按确定三秒：进入或离开家长设置。
- 设置页：上下选择，确定执行。
- 家长设置提供配网、确认后忘记网络、选择目的地和返回；随包只提供上海。

屏幕空闲 30 秒调暗、60 秒关闭背光；息屏后第一次按键只唤醒，不切换当前卡片。
有时限的家长配网过程中保持说明可见。这里控制背光，不使用 CPU 深度睡眠。

## 家长 Wi-Fi 配网

当前派生固件的小程序配网已被反馈无法使用，兼容性排查暂缓，本版先离线使用。
随包文案采用通用问候，不包含孩子姓名或昵称。

使用现有微信小程序 **蓝牙配网-FoloToy AI PASSPORT**。屏幕分两段显示完整
名称及状态；蓝牙设备名为 `BLUFI_Koala`。参考分支提交为
`9c039cc5127f22072afa83bedb7fa3d8efe635ad`，只借鉴联网与安全协商逻辑，
没有复用测试菜单、演示页面、BSP 或旧分区配置。

家长在手机上填写 2.4 GHz Wi-Fi 或手机热点名称和密码。只记住一个成功连接的
网络；新密码失败不会覆盖原来可用的凭据。开机在后台尝试已保存网络，连接窗口
为十秒；失败释放无线资源，不阻塞首页。配网最多持续两分钟，成功或退出后释放
蓝牙资源。密码不写入日志。未配网、失败或没网络都能继续离线探索。
连接路由器并取得 IP 不代表互联网可用。本版尚无联网校时、手机定位、在线对话
或内容下载；小程序及实际手机热点的兼容性仍须实机测试。

## 无须重新编译应用的卡包

第一版实现 USB 更新内容，不增加文件系统、手机上传页面、程序 OTA 或云服务。
`.klp` 包含版本化内容清单、每个目的地的 RGB565 背景，以及按包内中文生成的
28／36 像素字体子集。固定的 144 × 144 考拉图层和 24 像素系统字体保留在固件中。
现有问候、探索、回应可以换文字和背景而不编译 C；新增交互类型仍需升级固件。
家长设置可选择包内目的地，采用手动选择，重启后回到包内第一个目的地。

复制 `assets/packs/shanghai/cards.json` 和背景到新目录后编辑。每包 1–6 个
不重复目的地，每处 1–20 条问候和探索，标题 1–4 个字，对话遵守两行、每行
五字限制。卡包容量为 1 MiB；28 像素字体文件最多 16 KiB、36 像素最多
4 KiB，内容太多时拆成多个包。

生成工具需要 Python、Pillow 11.3.0、fontTools 4.60.1、Node.js，以及官方
`lv_font_conv` 1.5.3。在应用根目录运行，例如：

```text
python tools/pack_cards.py build assets/packs/shanghai/cards.json build/cards.klp --converter /path/to/lv_font_conv/lv_font_conv.js
python tools/pack_cards.py verify build/cards.klp
python tools/update_card_pack.py build/cards.klp
```

最后一条默认只核验，不打开串口。`--port COMxx --flash` 模式必须取得目标
设备刷写授权；工具先读取并核对设备分区表，再只写 `0x700000` 内容区并校验。
不擦整片 Flash，不写应用或 NVS。USB 更新会重启设备、替换整个内容包，
不是双槽原子更新；包损坏或写入中断时，开机会回退到固件内置上海包。
CRC 用于检测损坏，不是身份认证，只使用本地生成的可信卡包。

本应用保留 NVS／PHY；factory app 位于 `0x10000`，大小 `0x6f0000`；
新增 `travel_cards` 数据分区位于 `0x700000`，大小 `0x100000`。
完整验证镜像包含默认卡包。首次安装会改变分区布局，可能重置已有数据，遵循
[刷机与数据策略](engineering/firmware-layout.zh_CN.md#烧录与已存数据)；
后续内容更新要求设备已经采用兼容的第一版分区布局。

## 验证与交付

在编译主机激活 ESP-IDF 5.5.3 后运行 `./tools/validate.sh`。新增主机测试
覆盖交互、计时回绕、家长确认、按键位置、文字长度限制，以及卡包 CRC、截断、
溢出和数据重叠。`tools/render_travel.sh <pinned-lvgl-directory>` 额外使用真实
UI 代码、同版本 LVGL 和生成字体，渲染 240 × 320 页面；这属于软件验证，不是实机测试。

下载保留完整 BIN、匹配 ELF／MAP、manifest、`flash_args`、分区表、
bootloader／app 镜像和匹配 `.klp`，记录哈希及源码身份。
未经用户授权，不提交、推送、发布或执行 USB 写入。
