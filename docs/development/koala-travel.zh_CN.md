# 考拉旅行搭子

`feature/koala-travel` 应用开机直接进入自己设计的 240 × 320 旅行界面，启动和
导航路径均不经过基线硬件测试菜单。没有网络也可使用内置上海卡包、旅行印章册、
电量条和时钟；还可保存一份手机同步的自定义行程。自定义行程和印章记录存于 NVS。

## 显示、按键与动作

城市标题使用 36 像素字体，对话使用 28 像素字体，右侧按键提示使用 24 像素
字体。三个按键中心分别为 y=53、160、267，对应上、下、确定键。电量条显示
BSP 读取的真实电量；读数不可用时显示空条。

- 上键显示或轮换问候；进入一条问候时挥手一次。
- 下键显示或轮换探索任务；每条新任务随机向左或向右指一次。
- 确定键给当前任务盖章；印章显示三秒，回到主页后点头一次。
- 长按确定三秒进入或退出旅行印章册；上下键浏览任务，确定键返回主页。
- 长按上键三秒进入或退出网页同步维护模式。
- 长按下键三秒立即进入深度睡眠。

首次显示主页时挥手一次。新行程同步成功后，考拉走完两轮四帧步态，再挥手一次；
以后真实切换目的地或背景也复用这一入口。新动作会中断旧动作，结束后停在红帽
静态帧；印章册和维护页隐藏并取消动作。角色保持灰色可爱脸和身体、黄色背包、
蓝色相机，以及已确认的红色无图案鸭舌帽。

正常使用时背光为 75%，空闲 30 秒降到 20%，60 秒降到 10%；两分钟没有输入
后进入深度睡眠。睡眠前按任意功能键会恢复 75% 亮度，并正常执行该次按键动作。

## 手机网页同步

维护模式会启动名为 `Koala-Travel` 的热点，以及位于 `192.168.4.1` 的 HTTP
服务。手机可通过门户页面设置目的地名称、一至四条任务以及设备时间。有效行程
写入 NVS 后立即成为当前标题和任务列表；设备显示同步成功，两秒后自动回到主页。
网页同步不上传背景图片，也不改写卡包分区。

该网页只存在于临时热点内，不需要云账号或互联网。离开维护模式会停止热点和
HTTP 服务。

## 卡包与固件资源

第一版分区保留 NVS 和 PHY；factory 应用位于 `0x10000`，大小为 `0x6f0000`；
`travel_cards` 位于 `0x700000`，大小为 `0x100000`。有效卡包包含目的地背景、
文案和对应的 28／36 像素字库子集；替换卡包无效时回退到固件内置上海卡包。

考拉动画直接驻留 Flash，不整套复制到内部 RAM。`tools/pack_koala_frames.py`
把已确认的四张 2 × 2 RGBA 原画确定性转换为 20 帧、144 × 144 RGB565A8
图集，依次包含挥手、点头、右指、镜像左指和走路，共占用 1,244,160 字节 Flash。

## 验证与交付

在 ESP-IDF 5.5.3 环境运行 `./tools/validate.sh`。主机测试覆盖交互、动画时序、
中断重启、计时回绕、帧分组、卡包完整性和仓库检查。另可运行
`tools/render_travel.sh <pinned-lvgl-directory>`，使用真实 UI 代码渲染 240 × 320
页面和代表性动作帧；软件渲染不等于真机显示验证。

固件门禁保留完整镜像及匹配的 ELF、MAP、manifest、`flash_args`、bootloader、
分区表和应用镜像。仅在明确完整刷新时才把已验证的完整镜像写入 `0x0`；镜像填充
可能重置 NVS 和 PHY。编译或刷写成功不能证明屏幕动画、实体按键、射频和睡眠功耗。
