# 小朋友的西澳旅行伙伴

应用是面向 7 岁小朋友的 240 × 320 离线行程伙伴，介绍 2026 年 10 月 2–12 日
一家人去哪儿、做什么、有什么好玩。10 月 13 日的返程联程供语音问答使用，
设备仍保持 11 天。

## 页面与按键

首页始终介绍当天主题。上键依次查看路线、玩法、住宿和首页；下键打开并轮换
当天 1–3 项主要活动。活动页确定键作为备用，记录“玩过”；再次按下不会撤销。
已玩过的活动仍可查看，并区分已同步、待同步、已跳过和冲突状态。

首页单击确定开始准备语音，听到提示音后说话，再单击确定发送；准备中再按可取消，
回答期间再按会打断并开始新一轮。录音满 20 秒会自动结束；服务器 60 秒仍未完成回答时
结束本轮并显示语音错误。长按上键选择自动日期或某天预览，长按下键睡眠，首页双击上键
配网。配网持续 5 分钟后不再阻止自动睡眠；设备睡眠后可按键唤醒重新配网。
预览某一天不代表已经到达那里。
使用 Perth UTC+8 时间。

去掉检查行李、证件、补水等任务。不设积分、截止时间或必须全部完成的要求，
可选活动可以跳过；首页不会被清单或完成分数替代。

## 儿童内容与图片

编辑源是版本 3 的 `assets/packs/western-australia/cards.json`。每项活动有稳定 ID、
两行短文案和可选标记。同一份源导出服务端活动目录；交付时须核对行程 ID、
内容版本、活动 ID 和顺序。不能把旧提醒序号对应的完成位套到新活动上。

11 张原创绘本背景对应 11 天。保留红帽子考拉主角；10/9 的考拉采用 96 × 96
紧凑布局，旁边清楚露出 quokka，其他场景维持普通布局。必须检查实际
240 × 320 UI 和动画叠层，不能仅凭原图判断遮挡。

内容分区扩大为位于 `0x600000` 的 2 MiB；应用分区位于 `0x10000`，大小
`0x5f0000`。背景继续用 RGB565，并保留完整内置卡包回退。旧 1 MiB 布局的设备
必须拒绝直接写入新卡包，先迁移匹配的固件和分区表。完整镜像可能重置 NVS；
保留 Wi-Fi 等设置需要核对分段刷机方案。构建不代表获得刷机授权。

中文字形使用编译期 OFL Noto Sans SC 子集。文案改变后重新生成并验证字形覆盖
和实际控件宽度。

## 对话与进度归属

语音角色是小朋友的旅行伙伴，通常用自然的 1–3 句话回答，追问时再展开。
当前主线、可选活动和待确认事项分别表达；订单管理凭据与历史行程版本不进入
日常语音知识。

每轮先通过现有文本模型接口进行有界的活动判定，再校验和保存允许的进度变化，
最后流式生成自然回答。因此首句前会多一个短模型请求。只有成功写入才能说
“记下啦”。问句、未来计划和他人的经历不算完成；含糊表达先追问。支持明确
纠正和明确跳过。

活动判定与自然回答各有稳定、带版本的提示词前缀。日期、所看页面、权威进度及
本轮结果构成唯一一份可替换的动态尾部。判定 JSON 不进入扬声器或普通聊天历史。
聊天保留最近 8 个完整问答轮次，并限制为 12 KiB UTF-8；重连可清空聊天历史，
不会清空持久化活动进度。

设备遥测和活动进度分别管理：设备负责当前页面、日期、电量，服务端负责已同步
活动进度。设备上传旧快照不能覆盖服务端刚刚记录的活动。

## 离线记录与同步

断网时按确定立即记录本机完成状态，并持久化幂等操作；同一待同步活动的重复
按键合并。重启后操作仍在，界面能区分待同步与服务端已确认的状态。
联网恢复和说话前上传待同步操作；回答结束或被打断后刷新进度。

操作包含活动 ID、目标状态、内容版本、操作 ID 和预期活动修订号。服务端在事务
中验证。相同操作或已经相同的状态幂等成功；不同结果的修订冲突保留服务端结果，
通过明确纠正处理，不悄悄覆盖双方意图。目录版本不匹配时暂停写入并保留操作。
每个新接受的操作都会推进活动修订号，包括对当前状态的明确确认；重复提交同一
操作 ID 不会再次推进。因此，语音明确确认后可以解除设备冲突标记。

网络和音频回调只排队事件，由 UI 任务修改其持有的状态和界面。旧生活提醒的
完成位不迁移为儿童活动，日期选择、动画记录和独立 Wi-Fi 设置保留。

## 验证与交付

在 ESP-IDF 5.5.3 中运行 `./tools/validate.sh`。`tools/render_travel.sh` 使用固定版本
LVGL 渲染生产 UI；检查全部日期，以及 quokka 场景的进场、静止、活动、待同步、
跳过、冲突和语音状态。服务端验证须覆盖真正发给 mock LLM 的请求、两套前缀、
记录与不记录样例、离线重试、冲突和取消。

保留源码身份及匹配的合并 BIN、应用 BIN、ELF、map、分区镜像、flash_args 和归档
manifest，并核验下载哈希。构建、主机测试、实机测试和未验证项分别报告。
mock 音频不证明真实识别、麦克风或扬声器效果；Pi 局域网服务还需要单独验证
旅行中手机热点下的可达性。
