# 公开固件核心与私有内容

此分支提供应用核心、进度协议、资源工具、分区布局和主机测试。当前行程、背景
原图、生成卡包、配套字形子集和行程说明使用另行记录版本的私有覆盖包交付，
不随本次核心代码改动公开。

构建前，在独立工作区检出覆盖包 manifest 指定的固件提交，应用匹配的私有覆盖包，
逐文件核验哈希，并核对其活动目录与语音服务一致。随后运行 `./tools/validate.sh`
和生产 UI 渲染器。

该分支基线继承的旧内容不是可交付的版本 3 卡包，因此公开 checkout 本身不是
完整可刷写版本。不要跳过资源验证或用旧包替代内置回退；交付应用必须内置与内容
分区一致的完整、已验证卡包。

凭据和设备专用运行配置不进入 Git。刷写、数据保留与验证遵循既有固件布局及实机
测试流程。
